# DS 4002 CS3: Charlottesville Crime & Temperature Correlation Case Study
The present respository contains the directions, data, scripts, and reference materials needed to complete this case study looking at the correlation between crime and temperature in Charlottesville.

## Directions
Access the Hook and Rubric documents to get started. Beginning code for the Pearson correlation analysis is titled Template Script.ipynb and found in the SCRIPTS folder, and everything that must be completed by you is noted by a #COMPLETE comment. To finish this case study, submit your final GitHub respository (elaborated in Rubric) as a link that includes your slidedeck.

Three additional materials to guide and support you throughout completing this case study are found in the SUPPLEMENTARY MATERIALS folder.
